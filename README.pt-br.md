# Calculadora de Notas (Python)

[Read in English](README.md)

Programa de terminal que calcula a média das suas notas e mostra se você está aprovado, em recuperação ou reprovado.

## Como funciona

- Você escolhe quantas notas vai informar (por exemplo, 3 trimestres ou 4 provas).
- Cada nota deve ser um número de 0 a 10. A vírgula é aceita (6,5). Entradas inválidas são perguntadas de novo.
- O programa mostra a média e a situação:
  - média 7 ou mais: **Aprovado**
  - média de 5 até menos de 7: **Recuperação**
  - média abaixo de 5: **Reprovado**

Os limites 7 e 5 podem ser alterados no código para seguir a regra da sua escola.

## Como executar

É preciso ter o Python 3 instalado.

```
python calculadora_notas.py
```

Você também pode colar o código no [Google Colab](https://colab.research.google.com) e executar por lá.

## Conceitos praticados

Funções, laços `while`, `try/except`, validação de entrada, listas, `sum` e `len`, condicionais (`if/elif/else`) e formatação de texto.
